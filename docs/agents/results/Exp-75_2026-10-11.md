# Exp 75 (T-070) — S&P 500 à volatilité ciblée, levier plafonné ×3 — RÉSULTAT

- Préenregistrement : `docs/agents/hypotheses/Exp-75.md` (commit ba53a83, non modifié).
- Code : `scripts/agents/exp75_vol_target.py` ; tests : `tests/agents/test_exp75_vol_target.py` (11 tests, fixtures synthétiques). Script et tests commités (ab33c34) **avant** le calcul réel.
- Sorties : `Exp-75_2026-10-11_criteria.json` (tous les chiffres), `Exp-75_2026-10-11_daily.csv` (série quotidienne).
- Données : cache Exp 74 `data/exp74_yahoo/` (lecture seule ; Yahoo ^SP500TR, ^GSPC, ^IRX, ^NDX, ^RUT, ^RUTTR, ^GDAXI ; FRED DEXCAUS + CAD=X), jusqu'au 2026-10-09.
- Catégorie : **en échantillon** (backtest historique, aucune donnée forward). Remplissage : au cours de clôture t+1 de la décision prise à la clôture t. Coût : 0,10 % × |Δw| par rééquilibrage + 0,95 %/an sur le levier excédentaire ; la référence rééquilibre chaque jour gratuitement.
- Anti-doublon : Exp 74 (filtre MM200 ×2, mécaniquement PASS) et T-069 (revue : surplus = levier, pas d'avantage) ; le ciblage de volatilité n'apparaît avant que comme composant de stratégies crypto/comptes financés (H-R15-A, H-R17 `vol_target.py`, H-R18) ; aucun test antérieur sur indice actions contre un levier constant à volatilité égale.

## Verdict mécanique : **REJET**

Raison : l'écart de Sharpe sur la période entière est ≤ 0 sur **2 des 3** indices de contrôle (RUT −0,094 ; DAX −0,070 ; seul le NDX est positif, +0,137). C'est une condition de REJET du préenregistrement.

Les autres critères PASS ne sont pas remplis non plus :

| Critère | Valeur | Seuil | OK ? |
|---|---|---|---|
| 1. Écart de Sharpe entier, V=25 % | +0,017 | ≥ +0,10 | non |
| 1. Sharpe de la règle Pré / Post | 0,409 / 0,779 | > 0 | oui |
| 1. (lecture stricte) écart Pré / Post | +0,019 / +0,001 | > 0 | oui (de justesse en Post) |
| 2. Écart entier V=20 % / V=30 % | +0,022 / +0,037 | > 0 | oui |
| 3. Indices avec écart > 0 | 1 / 3 (NDX) | ≥ 2 | non |
| 4. CAGR Post V=25 % | 22,06 % | ≥ 15 % | oui |
| 4. MaxDD entier V=25 % | −69,6 % | ≥ −50 % | **non** |
| REJET : écart entier V=25 % ≤ 0 | +0,017 | — | non déclenché |
| REJET : 2 indices sur 3 ≤ 0 | RUT, DAX | — | **déclenché** |

En clair : sur le S&P, ajuster l'exposition selon la volatilité donne à peu près le même Sharpe qu'un levier constant de même volatilité (+0,017, bruit). Sur deux autres indices, ça fait pire. Et la baisse maximale (−70 % en 2000-2003) dépasse la limite de −50 % acceptée par l'auteur.

## Limites et anomalies

- **Interprétation du critère 1** : « et il est > 0 en Pré comme en Post » est ambigu (Sharpe de la règle ou écart). Le code exige les deux (lecture stricte) ; les deux lectures donnent le même résultat ici (critère 1 échoue de toute façon sur +0,017 < +0,10).
- **Pas de correction de proxy dans les chiffres décisionnels** (formule fixée par le préenregistrement). L'Exp 74 a mesuré que le ×3 synthétique bat UPRO de 1,8 pt/an ; la sensibilité ci-dessus (frais majorés) réduit l'écart entier à +0,005. Cela ne change pas le verdict.
- Le levier est financé au taux du T-bill (^IRX) sans marge d'emprunt : favorable aux deux côtés, plus à la règle (levier moyen 1,96 contre 1,51).
- Le coût de 0,10 % × |Δw| ne compte pas l'écart entre clôture et prix exécuté réel ; la règle trade ~22 fois par an, la référence jamais.
- Positions avant 1990 : la règle démarre en encaisse le 1988-01-04 et a 21 séances de préchauffage ; au 1990-01-01 elle est déjà en régime normal.
- DAX : rf US utilisé, devise EUR non convertie.
- NDX/RUT en prix seul : le levier excédentaire perd les dividendes des deux côtés à proportion de w ; la règle (levier moyen plus élevé) est un peu défavorisée.
- Le 1987 n'est pas dans la période évaluée (SP500TR commence en 1988).
