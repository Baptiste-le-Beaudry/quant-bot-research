## Limites

1. **En échantillon** ; P2 déjà vue. Erreur type de Δ ≈ 0,13-0,17 pt : même le Δ de P2 (+0,18) n'est qu'à ~1 σ. Le test peut rejeter, pas confirmer.
2. BTC dans P2 : 13 trades par tercile, Δ +0,85 pt sans valeur statistique.
3. Terciles définis sur toute la population (bornes vues après coup) : acceptable pour un diagnostic, pas pour un filtre live.
4. Barres Binance USDT-M ; exécution Jupiter spot non modélisée au-delà du coût `/build` (comme l'Exp 57).

## Compteur de multiple testing

1 variante décisionnelle (15 min, β 30 j, terciles), 1 variante rapportée sans effet (marché = BTC seul). 2 populations × 3 symboles. Aucune autre fenêtre, aucune autre découpe. Population et coûts de l'Exp 57 réutilisés tels quels.
